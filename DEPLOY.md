# Publish DINU RAATO KE READER💀🤫 as an installable web app

## Vercel
1. Push this project to GitHub.
2. Import the repository into Vercel.
3. `vercel.json` already selects `npm install`, `npm run build:web`, and `dist`.
4. Deploy.
5. Open the HTTPS site on your phone/tablet.
6. Android: browser menu → Install app / Add to Home screen.
7. iPhone/iPad: Safari Share → Add to Home Screen.

## Important
The static deployment intentionally does not run the Express Gemini server. PDF storage, bookmarks, highlights and reading progress remain local and work without login. The optional AI drawer requires a separately deployed API/server and a server-side Gemini key.
